# 9 Параметр оценки: государственная и отраслевая значимость

Рубрика используется для оценки того, показана ли предметная связь проекта с общественной, отраслевой или государственной задачей — а не только декларация о «важности для страны». Индикаторы рубрики строятся только по внутренним следам текста проекта. Вывод о технологическом суверенитете на этой рубрике не делается: для него позднее потребуется внешняя рамка сопоставления.

## Правило применения

Оценка по параметру ставится не по общему впечатлению, а по степени подтвержденности четырех критериев:

1) Внешняя задача указана конкретно;
2) Связь проекта с задачей предметна;
3) Масштаб эффекта показан;
4) Адресат эффекта определен.

Критерий считается подтвержденным, если в тексте проекта явно обнаружены наблюдаемые индикаторы данного критерия. Критерий считается неподтвержденным, если индикаторы отсутствуют, выражены слишком слабо или присутствуют выраженные антипризнаки.

Критерий считается подтвержденным, только если найденные фрагменты закрывают порог подтверждения, указанный для критерия. Формальные или частичные упоминания, не закрывающие порог, подтверждением не считаются.

Если в тексте проекта внешняя задача не отражена вовсе, параметр оценивается по нижней границе шкалы, а все недостающие основания фиксируются в missing_data.

## Разграничение с другими рубриками

Рубрика отвечает на вопрос «связан ли проект с внешней задачей предметно». Один и тот же фрагмент текста может подтверждать критерии разных рубрик, но вопросы у рубрик разные:

- рубрика 1 «Реальность проблемы» — существование проблемы у носителей; настоящая рубрика — соотнесение этой проблемы с внешней общественной, отраслевой или государственной задачей;
- рубрика 2 «Рыночный потенциал» — коммерческий масштаб потребности; настоящая рубрика — нерыночный, публичный масштаб эффекта;
- рубрика 7 «Путь к применению» — путь внедрения; настоящая рубрика — значимость результата вне контура внедрения.

## Критерии и наблюдаемые индикаторы

### 1) Внешняя задача указана конкретно

1. Суть критерия: в тексте названа конкретная общественная, отраслевая или государственная задача, а не общее благополучие.

2. Наблюдаемые индикаторы:
+ Названа задача в формулировке, узнаваемой во внешнем контуре: программа, стратегия, нацпроект, нормативный документ, отраслевой приоритет.
+ Указан документ, орган или программа, в рамках которых задача сформулирована.
+ Задача относится к предметной области проекта.
+ Из текста понятно, в чем состоит задача, а не только ее «важность».

3. Антипризнаки:
+ Значимость заявлена только декларацией: «важно для страны», «вносит вклад в развитие».
+ Задача названа так обще, что ее невозможно соотнести с документом или программой.
+ Заявленная задача не относится к предметной области проекта.
+ Раздел о значимости отсутствует полностью.

4. Порог подтверждения:
+ Для «подтверждено» задача должна быть узнаваема во внешнем контуре — с документом, органом или программой — и относиться к предметной области проекта. Декларации «важно для страны» и задача без соотнесения с документом или программой подтверждением не считаются.

### 2) Связь проекта с задачей предметна

1. Суть критерия: из текста видно, какой именно часть внешней задачи работает данный проект.

2. Наблюдаемые индикаторы:
+ Показано, какой элемент задачи закрывает проект: конкретный показатель, процесс, дефицит, класс случаев.
+ Связь проведена через содержание проекта (проблему, решение), а не через общие слова.
+ Понятно, что изменится в задаче в случае успеха проекта.
+ Связь с задачей согласуется с описанием проблемы и решения в других разделах.

3. Антипризнаки:
+ Связь сводится к перестановке слов: проект «направлен на» задачу без указания, что именно он в ней меняет.
+ Заявленная связь противоречит фактическому содержанию проекта.
+ Задача используется как фон, не влияющий на постановку работы.
+ Связь обоснована только категорией проекта («ИТ-проект — значит, цифровая экономика»).

4. Порог подтверждения:
+ Для «подтверждено» должно быть показано, какой элемент задачи проект закрывает и что изменится в случае успеха. Формула «проект направлен на задачу» и связь по одной лишь категории проекта подтверждением не считаются.

### 3) Масштаб эффекта показан

1. Суть критерия: из текста видно, насколько широко распространяется общественный или отраслевой эффект проекта.

2. Наблюдаемые индикаторы:
+ Указано, на какой круг субъектов распространяется эффект: отрасль, регион, группа организаций, категория граждан.
+ Эффект выражен в измеримых терминах: доля, число объектов, экономия, снижение риска.
+ Показано, из чего складывается масштаб: от числа носителей проблемы до публичного эффекта.
+ Масштаб согласован с описанной проблемой и рыночными разделами проекта.

3. Антипризнаки:
+ Масштаб эффекта не оценен: значимость не соотнесена ни с одним кругом субъектов.
+ Заявлен «огромный масштаб» без основания.
+ Масштаб противоречит остальным разделам проекта (например, описан один пилотный кейс, а эффект заявлен федеральным).
+ Эффект подменен значимостью самой темы.

4. Порог подтверждения:
+ Для «подтверждено» масштаб должен быть выражен в измеримых терминах и прослежен от носителей проблемы до публичного эффекта. «Огромный масштаб» без основания и подмена эффекта значимостью самой темы подтверждением не считаются.

### 4) Адресат эффекта определен

1. Суть критерия: из текста понятно, кто конкретно получает общественный или отраслевой эффект и в чем он состоит для этого адресата.

2. Наблюдаемые индикаторы:
+ Назван адресат эффекта: орган, отрасль, категория граждан, группа организаций.
+ Понятно, в чем эффект состоит для адресата: новый доступ, снижение издержек, безопасность, качество услуг.
+ Адресат эффекта соотнесен с носителями заявленной проблемы.
+ Отличены адресат публичного эффекта и коммерческий пользователь решения, если они не совпадают.

3. Антипризнаки:
+ Адресат эффекта не назван: непонятно, для кого существует «общественная значимость».
+ Адресат эффекта и пользователь решения смешаны так, что не видно публичного контура.
+ Заявленный адресат не соотнесен с проблемой и задачей проекта.
+ Эффект для адресата сформулирован только декларативно.

4. Порог подтверждения:
+ Для «подтверждено» адресат должен быть назван и соотнесен с носителями проблемы, а эффект для него — описан содержательно. Декларативный эффект и смешение адресата публичного эффекта с коммерческим пользователем без видимого публичного контура подтверждением не считаются.
